# Icon explorations

Saved icon-design outputs from a side-thread during theme 3 (2026-05-23).

## Files

- **`batch-01-stumps.png`** — 6 variants on stumps + ball + bails-being-hit. Gold-on-black, on-palette per DESIGN_HANDOFF. Strong silhouettes but a *batting-failure* framing — odd brand promise for a game where you ARE the rising batter. Also risks visual collision with Cricket League / Real Cricket / WCC in the App Store grid.
- **`batch-02-helmet-portrait-crown.png`** — 8 directions explored after the batch-01 critique: gold helmet, split-bg portrait silhouette, gold C-shield + helmet + star (career-badge feel), batter-in-swing silhouette, bat-and-ball, crown + ball, ball with motion lines, sunset silhouette.

## Strongest picks from the session discussion

1. **Batch 2, top row, position 2 — split-bg portrait silhouette.** Unique to this game; mirrors the (then-current) §16.3 portrait system. *Caveat:* the §16.3 portrait was later redesigned (face-as-Form replaces the split-bg horizon), so this direction reads slightly differently now but the brand-mark concept still works.
2. **Batch 2, top row, position 3 — gold C-shield with helmet + star.** Career-badge framing fits the roguelite-career genre. Distinct from any cricket-app neighbour in the App Store.
3. **Batch 2, bottom row, position 2 — crown + ball.** Speaks to *climbing to be king* — the roguelite progression metaphor.

## Status

Explorations, not selections. Icon work is downstream of the build — not on the critical path. Revisit once the game is closer to playable so the chosen icon reflects the actual game feel, not the early-design vibe.
