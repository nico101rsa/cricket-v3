How your build changes the runs you score (7c-1)

How to read this: we played the same even match (your team ★3 vs an opponent ★3) 2000 times for each of three Player builds. The X-axis is how many runs YOU personally scored in a match (0 on the left, up to ~130). Each curve shows one build: higher = more matches landed at that score. Each curve is scaled to its own peak so the *shapes* line up — a curve further right = you score more. The dashed vertical line is that build's average runs. (Built from the real game engine; 2000 matches × 3 builds.)

The curves slide right as you add batting points (Power + Composure). The bowling build peaks hard near 0 (you barely score); batting build's average is ~44 runs with a long tail past 100. The win-rate column is the real balance story: a batting build wins ~67% of even matches, but a bowling build only ~48% — basically no better than the balanced one. That's because your bowling Attributes (Attack/Control) don't affect the sim yet, so right now they're a wasted investment. The harness caught that automatically.
