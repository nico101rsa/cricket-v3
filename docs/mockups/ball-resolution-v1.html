Built by blending a defensive template (mostly dots & singles) toward an aggressive template (boundaries) by a scoring strength s = logistic(Power − Control + intent). The sim samples this with the seeded RNG.

Stage 1 — wicket curve

x: bowler Attack − batter Composure · y: P(wicket) per ball. Logistic — extreme mismatches saturate, never hit 0 or 100%. Dot = current contest.

Stage 2 — scoring curve

x: batter Power − bowler Control · y: scoring strength s (0 = block, 1 = attack). Same logistic family. Dot = current contest.
