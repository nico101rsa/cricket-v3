# Card Rescale to /100 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the whole game from the ~1–8 attribute scale to a /100 card scale (factor F = 6.25), behaviour-preserving at mid league, with proportional league scaling replacing the additive offset + floor.

**Architecture:** Two-stage migration per spec `2026-06-11-card-rescale-100-design.md` (DR1–DR14). **Stage A** (Tasks 1–10): pure ×6.25 rescale with every historical rounding point snapped to the old grid — gated by `probe_scoring_env.gd` printing digit-identical `154.7 / RR 8.20 / 6.27`, committed as ONE commit (a units change is atomic; the world must move together). **Stage B** (Tasks 11–15): drop the snaps, ★3-centred star map, offset→factor proportional scaling, creation/economy/save remap — each its own TDD'd commit. Then the re-verification ledger (Task 16) and close-out (Tasks 17–18).

**Tech Stack:** Godot 4.6.3 GDScript, GUT 9.6. Tabs in `.gd`. Suite: `/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests/unit -gexit` (no per-file filtering — judge red by parse-error/failing assert, green by count climbing past **428** and `All tests passed`).
```gdscript
class_name Attributes
extends Resource

# 4-attribute distribution used at Creation and during Career, on the /100 card
# scale (card-rescale spec 2026-06-11, DR1/DR3). SCALE converts one classic
# 1-8-era attribute point to /100 units; the save migration uses it too.
# Creation constraints: sum == 125, each in [5, 50]. NPC archetypes are exempt
# from the per-attribute cap (prior ruling; the bowler card carries 56.25).

const SCALE := 6.25            # /100 units per legacy attribute point (= 50/8)
const CREATION_TOTAL := 125.0
const CREATION_MIN := 5.0
const CREATION_MAX := 50.0

@export var power: float = 31.25
@export var composure: float = 31.25
@export var attack: float = 31.25
@export var control: float = 31.25

func sum() -> float:
	return power + composure + attack + control

func is_valid_creation_distribution() -> bool:
	if not is_equal_approx(sum(), CREATION_TOTAL):
		return false
	for v in [power, composure, attack, control]:
		if v < CREATION_MIN or v > CREATION_MAX:
			return false
	return true

func duplicate_typed() -> Attributes:
	var copy := Attributes.new()
	copy.power = power
	copy.composure = composure
	copy.attack = attack
	copy.control = control
	return copy
```

(Note: `CREATION_MIN` lands at its final Stage-B value 5.0 directly — Stage A's grid only ever
produces 6.25+ so the looser floor changes nothing at Stage A and saves a second edit.)

- [ ] **Step 4: gap-fill goes float** (Stage A: step = one legacy point, exact for 6.25-multiple deficits; Stage B re-steps it):

```gdscript
static func build_xi(player_attrs: Attributes, ppos: int) -> Array:
	var xi := standard_xi()
	var displaced: Attributes = xi[ppos - 1]
	var deficit := (displaced.power + displaced.composure) - (player_attrs.power + player_attrs.composure)
	xi[ppos - 1] = player_attrs
	_apply_batting_gapfill(xi, ppos, deficit)
	return xi

static func _apply_batting_gapfill(xi: Array, ppos: int, deficit: float) -> void:
	if is_zero_approx(deficit):
		return
	var dir := 1.0 if deficit > 0.0 else -1.0
	var remaining := absf(deficit)
	var slots: Array[int] = []
	for i in range(0, 11):   # 0 -> 10, top to tail
		if i != ppos - 1:
			slots.append(i)
	var idx := 0
	while remaining > 0.0:
		var step := minf(Attributes.SCALE, remaining)   # final step is fractional (DR9)
		var slot: int = slots[idx % slots.size()]
		var a: Attributes = xi[slot]
		if (idx / slots.size()) % 2 == 1:   # sweep 0 = composure, sweep 1 = power, ...
			a.power = maxf(Attributes.SCALE, a.power + step * dir)
		else:
			a.composure = maxf(Attributes.SCALE, a.composure + step * dir)
		remaining -= step
		idx += 1
```
(Walks in one-legacy-point chunks top-first as before — exact for Stage A's 6.25-multiple
deficits — with a fractional final chunk so any float deficit conserves exactly. Floor while
docking can strand deficit, same as the integer era.)
