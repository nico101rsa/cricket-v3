Player headwear · hats & helmets

Eight headwear shapes for the player portrait system. The face, neck, sky and horizon are identical on every card — only the headwear changes — so we can pick the most distinctive 1–2 silhouettes. Each is CSS-drawn (no SVG, no licensed marks). Bottom strip shows how each shape collapses at scorebar size: silhouette legibility at 32px is the real test.

Picking + next moves

  • Strongest at scorebar size (the real test): H1 Test grille, C2 Snapback, C3 Sun hat — each has a distinct outline. H2 and C1 are too domelike at 32px and risk reading as the same blob.
  • Map to game state, not just identity: helmet = batting only. Cap = fielding / bowling. H4 Battle-scarred works as a per-batter state overlay (after 50, after long innings) on top of H1/H2/H3.
  • Country palette already drives the helmet/cap colour via --country-1/2 in the in-match file — these mocks hard-code colours so the shape reads. When approved I'll port them to use the country variables.
  • What's missing: distinctive face features — facial hair, hair colour/length, skin tone, eye style. That's the next round — say the word and I'll mock 4 face features + 4 facial-hair variants in the same format.
  • IP-safe by construction: no franchise logos, no real player likenesses, no IPL trade dress. Marks are abstract (roundel, single-letter wordmark, gold crest).
